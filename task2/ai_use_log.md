# AI Use Log

## 1. Purpose

AI tools were used to support curriculum analysis, organise job-market findings, generate practical learning exercises, and develop proposed curriculum improvements. AI-generated content is treated as a starting point and requires verification against official sources and practical results.

## 2. AI-Assisted Activities

| Activity | Purpose | Verification approach |
|---|---|---|
| Curriculum audit | Identify topics to keep, update, reduce, or add | Compare recommendations with the official curriculum and programme regulations |
| Job-market analysis | Map course content to employer requirements | Check the original job descriptions, publication dates, and required skills |
| Practical exercises | Develop exercises for selected subjects | Run the exercises, inspect outputs, and test examples |
| Workflow redesign | Develop an improved college-process proposal | Check the process against the documented workflow and defined test cases |
| Credit redesign | Estimate the effect of proposed curriculum changes | Recalculate credits using the verified programme structure |

## 3. Verification Principles

- Official programme documents take priority over AI-generated summaries.
- Job requirements must be supported by the original employer postings.
- Course credits must be checked against the applicable curriculum version.
- Generated code and analytical outputs must be tested before being treated as correct.
- Assumptions and estimates must be distinguished from observed facts.
- Recommendations must not be presented as approved institutional changes.

## 4. Limitations

AI-generated recommendations may omit institutional requirements, misinterpret course titles, or suggest changes that conflict with prerequisites or accreditation rules. Final recommendations therefore require source verification and appropriate academic review.
